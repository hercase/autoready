AutoReady

Questions

What AutoReady installs, what it sends, and everything else that doesn't fit in the app.

Installing

What gets installed?

Everything is for your user only and needs no admin rights:

  • The app in %LOCALAPPDATA%\Programs\AutoReady.
  • Shortcuts in the Start menu and, if you choose, on the desktop.
  • An entry in Settings → Apps, to uninstall it like any other app.
  • Start with Windows, if you leave it on: a startup entry for your user.
  • A Game State Integration file in the folders of supported games (Dota 2 and CS2 today). It's Valve's official way for tools to know when you're in a match; the game only talks to AutoReady on your own PC (127.0.0.1).
  • Settings and logs in %APPDATA%\AutoReady.

It never touches game memory or game files. It only changes your Steam launch options if you click Set up, and it keeps the ones you already had.

How do I uninstall it?

Settings → Apps → Installed apps → AutoReady → Uninstall. It removes the app, its shortcuts, the startup entry and the Game State Integration files, and asks whether to delete your settings too.

Windows shows a SmartScreen warning

Windows warns about apps it hasn't seen much yet, and AutoReady is new. AutoReady is not code-signed yet; we plan to apply for a free open-source certificate again as the project grows. Until then, click More info → Run anyway. Every release is built from the public source code and scanned with Microsoft Defender.

Privacy

What does AutoReady send, and to whom?

No accounts, analytics or telemetry. It only goes online for these, and each one can be turned off:

  • Updates (GitHub): checks for a new version at startup and once a day.
  • Your Steam status (Steam Community): reads the public status of the Steam account on this PC (for example "Finding a match") while your game is open, to know when you're playing. You choose it in the installer, and you can turn it off later with UseSteamStatus=False in %APPDATA%\AutoReady\autoready.ini.
  • Phone notifications (ntfy): only if you turn them on, and only the notification text.

During the beta it keeps a few screenshots of the game window on your PC to improve detection; they're never uploaded. Full details in the privacy policy.

Using it

Can I get banned for this?

AutoReady only looks at the game window and presses Accept, like you would. It doesn't read or change game memory and doesn't inject anything. Steam's terms do mention automation software, so the risk isn't zero, but nothing here touches the match itself. For League of Legends it uses the client's local API instead, which Riot doesn't officially document: community tools have used it for years, but it's a gray area (and not allowed in Korea).

Does it click anything during a match?

No. Once a match starts it stops looking until you're back in the menu. If it can't tell whether a match started, it pauses itself after accepting and lets you know.

Should I leave it on all the time?

Yes, that's the idea: you never know when the match will pop. Pause it with your hotkey or the switch at the top of the panel if you don't want a match; the pause lasts until you resume it or close the game.

How do phone notifications work?

Turn on Phone notifications in the AutoReady panel, click Show code and scan the QR with your phone camera. It opens a short setup page that connects the free ntfy app: one tap on Android, copy and paste on iPhone. Always start from that QR: the page only works with your code in the link.

Your code looks like ar-k7m2q. Keep it private: anyone with it can read your notifications.

Doing it by hand on iPhone:

  • Install the free ntfy app from the App Store, open it and tap Allow when it asks about notifications.
  • Tap + at the top right, paste your code in Topic name and tap Subscribe.
  • In AutoReady, click Send test. If nothing arrives, check that notifications for ntfy are on in the iPhone Settings and that a Focus mode isn't silencing them.
Can I use it to stay AFK?

No. It's there so you don't miss a match while you grab something. Accept, then come back: leaving hurts the other nine players.

Does it work with two monitors?

It should, wherever the game is. Multi-monitor setups are still being tested, so if something's off, let us know.

Will you add my game?

Probably, if it shows an Accept button when a match is found. Ask for it here; a screenshot of the popup helps a lot.

It didn't accept my match

Check that the switch at the top of the panel is on and that there's no Set up button. If it still fails, tell us your game, screen resolution and Windows display scale.

Preguntas frecuentes

Qué instala AutoReady, qué manda, y todo lo que no entra en la app.

Instalación

¿Qué se instala?

Todo es solo para tu usuario y no necesita permisos de administrador:

  • La app, en %LOCALAPPDATA%\Programs\AutoReady.
  • Accesos directos en el menú Inicio y, si querés, en el escritorio.
  • Una entrada en Configuración → Aplicaciones, para desinstalarla como cualquier app.
  • Iniciar con Windows, si lo dejás activado: una entrada de inicio para tu usuario.
  • Un archivo de Game State Integration en las carpetas de los juegos compatibles (hoy, Dota 2 y CS2). Es la forma oficial de Valve para que una herramienta sepa cuándo estás en partida; el juego solo le habla a AutoReady dentro de tu PC (127.0.0.1).
  • La configuración y los logs, en %APPDATA%\AutoReady.

Nunca toca la memoria ni los archivos del juego. Solo cambia tus opciones de lanzamiento de Steam si tocás Configurar, y conserva las que ya tenías.

¿Cómo lo desinstalo?

Configuración → Aplicaciones → Aplicaciones instaladas → AutoReady → Desinstalar. Borra la app, sus accesos directos, la entrada de inicio y los archivos de Game State Integration, y te pregunta si querés borrar también tu configuración.

Windows muestra un aviso de SmartScreen

Windows avisa sobre las apps que todavía vio poco, y AutoReady es nueva. Todavía no está firmada; vamos a volver a pedir un certificado gratuito para código abierto a medida que el proyecto crezca. Mientras tanto, tocá Más información → Ejecutar de todas formas. Cada versión se compila desde el código público y se escanea con Microsoft Defender.

Privacidad

¿Qué manda AutoReady, y a quién?

Sin cuentas, estadísticas ni telemetría. Solo se conecta a internet para esto, y cada cosa se puede apagar:

  • Actualizaciones (GitHub): busca una versión nueva al iniciar y una vez por día.
  • Tu estado de Steam (Comunidad de Steam): lee el estado público de la cuenta de Steam de esta PC (por ejemplo "Buscando partida") mientras tu juego está abierto, para saber cuándo estás jugando. Lo elegís en el instalador, y después lo podés apagar con UseSteamStatus=False en %APPDATA%\AutoReady\autoready.ini.
  • Avisos al celular (ntfy): solo si los activás, y solo el texto del aviso.

Durante la beta guarda algunas capturas de la ventana del juego en tu PC para mejorar la detección; nunca se suben. Todo el detalle en la política de privacidad.

Uso

¿Me pueden banear?

AutoReady solo mira la ventana del juego y toca Aceptar, como lo harías vos. No lee ni cambia la memoria del juego y no inyecta nada. Los términos de Steam mencionan el software de automatización, así que el riesgo no es cero, pero nada de esto toca la partida en sí. En League of Legends usa la API local del cliente, que Riot no documenta oficialmente: las herramientas de la comunidad la usan hace años, pero es una zona gris (y en Corea no está permitida).

¿Hace click en algo durante la partida?

No. Cuando arranca la partida deja de mirar hasta que volvés al menú. Si no puede saber si arrancó, se pausa sola después de aceptar y te avisa.

¿Lo dejo activo todo el tiempo?

Sí, esa es la idea: nunca sabés cuándo va a aparecer la partida. Si no querés una partida, pausalo con tu tecla o con el interruptor de arriba del panel; la pausa dura hasta que lo reanudes o cierres el juego.

¿Cómo funcionan los avisos al celular?

Activá Avisos al celular en el panel de AutoReady, tocá Mostrar código y escaneá el QR con la cámara del celular. Se abre una página corta de configuración que conecta la app gratis ntfy: un toque en Android, copiar y pegar en iPhone. Empezá siempre desde ese QR: la página solo funciona con tu código en el link.

Tu código se ve así: ar-k7m2q. No lo compartas: con él se pueden leer tus avisos.

A mano en iPhone:

  • Instalá la app gratis ntfy desde App Store, abrila y tocá Permitir cuando pregunte por las notificaciones.
  • Tocá + arriba a la derecha, pegá tu código en Topic name y tocá Subscribe.
  • En AutoReady, tocá Enviar prueba. Si no llega nada, fijate que las notificaciones de ntfy estén activadas en la Configuración del iPhone y que ningún modo de concentración las esté silenciando.
¿Lo puedo usar para quedarme AFK?

No. Está para que no pierdas una partida mientras buscás algo. Aceptá y volvé: irte perjudica a los otros nueve jugadores.

¿Funciona con dos monitores?

Debería, en el monitor donde esté el juego. Los equipos con varios monitores todavía se están probando, así que si algo falla, avisanos.

¿Van a agregar mi juego?

Probablemente, si muestra un botón de Aceptar cuando encuentra partida. Pedilo acá; una captura del aviso ayuda mucho.

No aceptó mi partida

Fijate que el interruptor de arriba del panel esté activado y que no aparezca el botón Configurar. Si igual falla, contanos tu juego, la resolución de pantalla y la escala de Windows.
